# Proposal: Add Blacksmith Shop and Quest Level 2

## Overview
Add a new blacksmith tab to the Study-RPG interface where players can spend currency/materials to upgrade their weapons. Upgrading the weapon will unlock access to Quest Level 2.

## Changes
- Create a Blacksmith tab component in the UI.
- Implement weapon upgrade logic (stats and cost).
- Add a condition check to unlock Quest Level 2 once an upgrade is purchased.
